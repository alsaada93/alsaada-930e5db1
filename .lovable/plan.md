# خطة: تحويل الحاسبة إلى منصة ذكية لتصميم المشاريع

الطلب ضخم (٢٠ ميزة + معدات لكل نوع مشروع). سأبنيه على **٥ مراحل** قابلة للتشغيل، كل مرحلة تُسلَّم وتعمل قبل التالية. أبدأ بالمرحلة ١ فور الموافقة.

## الأساس (هيكلة جديدة أنظف)

أوسّع قاعدة البيانات الحالية بدل إعادة بنائها من الصفر:

- **`restaurant_equipment`** (موجود): أضيف حقولاً جديدة:
  - `condition` (نص: جديد / مستعمل)، `used_condition` (جيدة/ممتازة/شبه جديد/غير مستخدمة)
  - `specs` (jsonb لمواصفات حرة: بلد الصنع، القدرة...)، `images` (مصفوفة صور)
  - `linked_listing_id` (ربط اختياري بإعلان مطابق)، `tier` (اقتصادي/متوسط/احترافي)
  - `essential` (أساسية أم إضافية)، `cost_layer` (أساسية/إضافية/تجهيزات تشغيل)
- **`restaurant_packages`** (جديد): الباقات الجاهزة لكل نوع مشروع (اقتصادية/متوسطة/احترافية) + قائمة معدات كل باقة وكمياتها.
- **`restaurant_calc_settings`** (موجود): أخزّن فيه إعدادات قابلة للإظهار/الإخفاء (الكهرباء، الماء، الصيانة، خطة التمويل...).
- **`saved_restaurant_projects`** (موجود): يُستخدم للحفظ والمشاركة، أضيف `share_slug` عمومي للقراءة.
- **`restaurant_leads`** (جديد): بيانات العملاء (اسم + واتساب + المشروع).

كل جدول جديد يحصل على GRANT + RLS مناسبة (المشرف يدير، القراءة عامة للمعدات/الباقات، الـ leads إدخال عام وقراءة للمشرف فقط).

## المرحلة ١ — لوحة تحكم المعدات + الباقات (نبدأ هنا)
- ميزات: ٢ (اقتراح حسب النوع)، ١ (باقات جاهزة)، إدارة المعدات الكاملة.
- إدارة كل معدة من لوحة التحكم: إضافة/إخفاء، صور متعددة، مواصفات، سعر جديد قبل/بعد الخصم، سعر مستعمل + حالته، بلد الصنع.
- خيار «يوجد إعلان مطابق»: قائمة منسدلة تعرض الإعلانات المعروضة مع السعر والتفاصيل بشكل مرتب ومختصر، وربطها بالمعدة.
- بناء الباقات الثلاث (اقتصادية/متوسطة/احترافية) لكل نوع مشروع، وإدخال المعدات الافتراضية لكل نوع (مطعم، كوفي، مخبز، مطبخ مركزي، وجبات سريعة، عصائر، حلويات، مخصص) كبيانات نموذجية تُعدَّل لاحقاً.

## المرحلة ٢ — تجربة المستخدم الذكية في صفحة الحاسبة
- اختيار نوع المشروع → عرض المعدات المقترحة + زر «أضف المقترح دفعة واحدة».
- زر «صمّم لي المشروع» (ميزة ٩) يبني الباقة تلقائياً.
- ميزة ٣ (المساحة m²) + ميزة ٤ (مستوى التشغيل: Startup/Medium/High) تغيّران الكميات تلقائياً.
- ميزة ٥ (اقتراح المعدات الناقصة) عبر قواعد بسيطة (قلاية+شواية → شفاط أقوى + ثلاجة...).
- بطاقات معدات جميلة تعرض الصور والمواصفات والسعر، وإن وُجد إعلان مطابق تظهر قائمة منسدلة بالإعلان وسعره.

## المرحلة ٣ — الحاسبة المالية الذكية
- ميزة ٦: تقسيم التكلفة ٣ طبقات (أساسية/إضافية/تجهيزات تشغيل).
- ميزة ٧: تكلفة تشغيل أولي (كهرباء/ماء/صيانة) — كل بند قابل للإظهار/الإخفاء من لوحة التحكم.
- ميزة ٨: مقارنة جديد vs مستعمل ذكية (نسبة توفير + الفرق + توصية نصية).
- ميزة ١٨/١٩/٢٠ (اختيارية قابلة للإخفاء): إجمالي افتتاح المشروع بنطاق أدنى/أعلى، نقطة التعادل اليومية، خطة تمويل بالأقساط.

## المرحلة ٤ — الحفظ والمشاركة والتصدير و Leads
- ميزة ١١: حفظ المشروع/تعديله/مقارنته بمشروع آخر.
- ميزة ١٣: رابط مشاركة عام `/restaurant/project/$slug`.
- ميزة ١٢: تصدير PDF احترافي (اسم المشروع + المعدات + الصور + الأسعار + الإجمالي).
- ميزة ١٤: نموذج Leads (اسم + واتساب) عند إكمال المشروع، تُحفظ وتظهر للمشرف.

## المرحلة ٥ — لمسات تجارية وتحسينات
- ميزة ١٥ (فلترة: الأرخص/الأعلى جودة/الأكثر استخداماً)، ١٦ (مقارنة معدتين)، ١٧ (الأكثر شراءً/Trending).

## ملاحظات تقنية
- البيانات تُجلب عبر `createServerFn` + TanStack Query؛ الإعلانات المطابقة من جدول `listings` (status=approved).
- لوحة التحكم تحت `/admin/restaurant` و`/admin/calculator` الحاليتين.
- لا ذكاء اصطناعي مطلوب الآن — «صمّم لي المشروع» يعتمد قواعد + الباقات. يمكن لاحقاً ربطه بـ Lovable AI إن رغبت.
