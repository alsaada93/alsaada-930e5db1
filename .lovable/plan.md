# خطة: تطبيق حراج السعادة للمتاجر (Capacitor)

## الفكرة
نبقي الموقع الحالي كما هو بتصميمه وبياناته وقاعدة بياناته (Lovable Cloud)، ونضيف طبقة **Capacitor** تحوّله إلى تطبيق جوال حقيقي (iOS + Android) بأيقونة وشاشة بداية وميزات أصلية، ويُرفع على App Store و Google Play. التطبيق يتصل مباشرة بنفس backend الحالي — أي إعلان أو تعديل في لوحة التحكم يظهر في التطبيق فوراً.

هذا ليس مجرد "ويب فيو": نضيف قدرات أصلية (كاميرا، مشاركة، إشعارات، تخزين آمن) عبر إضافات Capacitor الرسمية، ويعمل بملء الشاشة كتطبيق مستقل.

## ما سيتم عمله داخل Lovable

### 1. تجهيز الأساس
- إضافة حزم Capacitor: `@capacitor/core`, `@capacitor/cli`, `@capacitor/ios`, `@capacitor/android`.
- إنشاء ملف `capacitor.config.ts` باسم التطبيق `حراج السعادة`، ومعرّف الحزمة (مثل `sale.alsaada.app`)، وربطه بعنوان الموقع المنشور.
- ضبط الإعدادات لتعمل كتطبيق كامل الشاشة مع دعم RTL والعربية.

### 2. الهوية البصرية للتطبيق
- أيقونة التطبيق (App Icon) من شعار حراج السعادة بكل المقاسات المطلوبة للمتجرين.
- شاشة بداية (Splash Screen) بألوان الهوية (الأزرق الداكن + البرتقالي).
- ضبط لون شريط الحالة (Status Bar) ليطابق هوية الموقع.

### 3. تحسينات تجربة التطبيق
- شريط تنقّل سفلي (Bottom Tab Bar) مناسب للجوال: الرئيسية، العروض، إضافة إعلان، حسابي.
- زر الرجوع الفيزيائي (Android) يعمل بشكل صحيح داخل التطبيق.
- تكامل الكاميرا/المعرض عند إضافة إعلان عبر `@capacitor/camera` (اختياري لتجربة أصلية أفضل).
- ميزة المشاركة الأصلية للإعلانات عبر `@capacitor/share`.

### 4. الاتصال بالـ backend
- التطبيق يستخدم نفس اتصال Lovable Cloud الحالي بدون أي تغيير في البيانات.
- ضبط المصادقة (تسجيل الدخول / OAuth) لتعمل داخل التطبيق.

## ما يجب أن تعمله أنت خارج Lovable (لا مفر منه لأي تطبيق متجر)
هذه خطوات المتاجر لا يمكن لأي أداة تخطّيها:
1. **حساب Apple Developer** (99$ سنوياً) للنشر على App Store.
2. **حساب Google Play Developer** (25$ مرة واحدة).
3. جهاز/بيئة للبناء النهائي: Xcode لنظام iOS (يتطلب جهاز Mac)، و Android Studio لنظام Android.
4. سأزوّدك بالأوامر والخطوات الكاملة لتصدير المشروع من Lovable (عبر GitHub) وفتحه في Xcode/Android Studio وبنائه ورفعه.

```text
┌─────────────────────────────┐
│   نفس الموقع (التصميم/الكود) │
│   + Lovable Cloud (البيانات)│
└──────────────┬──────────────┘
               │ Capacitor
      ┌────────┴────────┐
   iOS (App Store)  Android (Google Play)
```

## ملاحظات تقنية
- المشروع يستخدم TanStack Start (SSR). للتطبيق سنضبط Capacitor على وضع يعتمد على الموقع المنشور (server URL) لضمان عمل SSR والبيانات الحية، وهي الطريقة الموصى بها لتطبيقات المتاجر المشبوكة بالخادم.
- لن يتغيّر أي شيء في الموقع الحالي على الويب — يبقى يعمل كما هو، ونضيف فقط مخرجات التطبيق.
- البناء والرفع النهائي للمتاجر يتمّان خارج Lovable (لا يمكن لأي منصّة ويب بناء ملفات `.ipa`/`.aab` ورفعها للمتاجر نيابةً عنك).
